Java Overview

Java is an object-oriented programming language developed by Sun Microsystems in 1995.

We use Java in OOP class because it enforces strict syntax and strong typing.

System.out.println("Hello HAU IT!");
JVM and JDK

To write and run Java programs on your machine, you need to understand these tools.

Key terms used when setting up your environment:

  • JDK stands for Java Development Kit.
  • JVM stands for Java Virtual Machine which runs bytecode.
  • Bytecode is stored inside .class files.
javac Main.java
Data Types

Java requires you to declare variable types before using them in code.

Primitive data types include int, double, boolean, and char.

int studentId = 20241001; double gpa = 1.25;
If Else Conditions

Conditional logic helps your program decide which block of code to run.

You can test multiple logical conditions using these keywords:

  • Use if for the main condition.
  • Use else if for secondary checks.
if (grade >= 75) { System.out.println("Passed"); }
Creating Classes

Everything in Java is wrapped inside a class structure.

Your main code must always sit inside a class with a matching file name.

public class Main { public static void main(String[] args) { System.out.println("Ready"); } }
